## 内容依据

- 改约超时案例来自公开的前端评测演示。V0 换键重试被拒绝，V2 用原键查账并回读订单，最终回复带可查回执。封面概括 V2 超时后的三步，展示的是示例轨迹。 [固定版本轨迹数据](https://github.com/Xaxrich/eval-platform/blob/28057761677d98aeacbde14a7fbd77701745431a/src/data/traces.ts)
- “放量前”段落是案例的评估设想。拟比较有回执的任务成功率、重复写入率，以及摊入模型、工具、重试和人工核对成本的成功任务成本。
- Claude Code Mini 的定位沿用教学实现，AI Cost Dashboard 的定位沿用自填支出报告原型。文中分别讨论动作权限切分，以及用手动填报验证订阅决策价值。 [教学实现 README](https://github.com/Xaxrich/claude-code-mini/blob/ef268fd3e3126a83ee77b838b62f5fa77cbb1824/README.md) · [原型 README](https://github.com/Xaxrich/ai-cost-dashboard/blob/7bfa4bdaa1f0a33148d5ca11f615ca3185070c21/README.md)

## 发布前验证

检查了四个 WebP 的尺寸、浏览器实际加载的字体与画布内的文字边界。四图每张分别约 23 KB 至 35 KB，浏览器为访客选择其中一张。GitHub Markdown API 保留了图片替代文本、配色和尺寸规则、案例链接与两个可展开区。在 Chrome 中用 GitHub 渲染后的正文验证了 320、390、640、641、800、1152 px 的素材选择和水平溢出，以及 390 px 时用键盘打开详情。
